# Cuaderno Teórico-Práctico de Facultad 🎓

Repositorio personal destinado a recopilar, documentar y llevar a la práctica aquellos conceptos teóricos y técnicos de la facultad que resulten interesantes, curiosos o aplicables al desarrollo de software y ciencias de la computación.

Cada tema cuenta con su fundamentación matemática o teórica y una implementación práctica (código, pruebas o simulaciones).

## 📂 Organización del Repositorio

La estructura se divide por materias o áreas del conocimiento:

```text
.
├── README.md                           # Índice general y presentación
└── <materia>/                          # Carpeta por materia (ej. discreta)
    └── <tema-proyecto>/                # Proyecto o tema específico
        ├── README.md                   # Explicación teórica y casos de uso
        ├── docs/                       # Diagramas, gráficos y esquemas
        └── ...                         # Código fuente e implementaciones
```

---

## 📌 Metodología de Documentación

Para cada nuevo tema incorporado se procura mantener:
1. **Fundamentos Teóricos:** Modelos matemáticos, definiciones formales y diagramas conceptuales.
2. **Implementación Práctica:** Traducción del modelo teórico a código limpio, modular y funcional.
3. **Casos de Uso / Ejemplos:** Demostraciones de aplicación y equivalencias entre la teoría y la práctica.
